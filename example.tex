\section*{Function Definition Style}

Functions are defined in Lean-4 style: name, then type, then body, joined by \(\defeq\). Multi-argument functions use the product type

\begin{enumerate}[label=\textbf{Example \arabic*.},leftmargin=*]
  \item Simple inline function:
  \[
    f : \RR \to \RR \defeq x \map x^2
  \]

  \item Multi-argument function via product type:
  \[
    g : \RR \times \RR \to \RR \defeq (x, y) \map x + y
  \]

  \item Identity function (parametric type):
  \[
    \mathrm{id} : A \to A \defeq x \map x
  \]

  \item Function with cases:
  \[
    \mathrm{sign} : \RR \to \{-1, 0, 1\} \defeq x \map
    \begin{cases}
      1,  & x > 0, \\
      0,  & x = 0, \\
      -1, & x < 0
    \end{cases}
  \]

  \item Restricted codomain (positive outputs only):
  \[
    \mathrm{sq} : \RR \to \RR_{\geq 0} \defeq x \map x^2
  \]

  \item Partial operator (subset-type domain):
  \[
    \mathrm{half} : \{n \in \ZZ \mid n \text{ even}\} \to \ZZ
    \defeq n \map n / 2
  \]

  \item Application of an anonymous mapsto (parens needed):
  \[
    (x \map x^2)(3) = 9
  \]

  \item Nested application (direct, preferred over $\circ$ composition):
  \[
    h \defeq x \map f(g(x)),
    \qquad f(y) \defeq y + 1,\ g(y) \defeq y^2
  \]
\end{enumerate}
